# Sienna Spiro — Great Expectation (Lyrics Player) ♫

Aesthetic & Synchronized Lyrics Player untuk lagu **Great Expectation** oleh **Sienna Spiro**, menghadirkan pengalaman visual lirik lagu dengan ketikan dinamis (*smooth typewriter*) yang tersinkronisasi presisi dengan vokal dan ketukan lagu.

## ✨ Fitur Utama

- **Versi Terminal / CLI (`greatexpectation.py`)**:
  - Tampilan ultra-bersih tanpa elemen yang mengganggu (hanya lirik yang mengalir estetik).
  - Menggunakan palet warna TrueColor ANSI (Warm Amber, Soft Gold, Luminous White).
  - Efek ketikan halus (*typewriter*) yang kecepatannya disesuaikan dengan nafas dan intonasi vokal.
  - Alur edit TikTok: Dimulai langsung dari Chorus 1 (00:37) lalu menyambung langsung ke Bridge, Climax Chorus, hingga Outro.

- **Versi GUI Layar Mandiri (`gui_lyrics.py`)**:
  - Layar aplikasi mandiri bergaya Apple Music / iPad Player.
  - Background ambient blur berwarna *Warm Amber & Terracotta Glow*.
  - Menampilkan album art cover oranye khas Sienna Spiro di sisi kiri dan scrolling live lyrics di sisi kanan.

## 🚀 Cara Menjalankan

### 1. Versi Terminal (Paling Ringan & Estetik)
Cukup jalankan perintah:
```bash
python greatexpectation.py
```
*(Atau klik ganda file `run_terminal.bat` di Windows)*

> **Tips:** Posisikan lagu di Spotify atau YouTube pada detik **00:37** (awal Chorus 1), lalu jalankan skripnya untuk sinkronisasi sempurna.

### 2. Versi GUI (Layar Mandiri)
Jalankan:
```bash
python gui_lyrics.py
```
*(Atau klik ganda file `run_gui.bat`)*

---

## 📦 Kebutuhan Sistem

- Python 3.8 atau yang lebih baru
- Pustaka Pillow (hanya untuk versi GUI):
  ```bash
  pip install pillow
  ```
*(Versi terminal `greatexpectation.py` dapat berjalan 100% tanpa perlu instalasi library tambahan/zero external dependencies).*
